# Python Mini Projects

A collection of small Python projects focused on programming fundamentals, problem solving, games, utilities, desktop tools, file handling, and practical applications.

## Projects

1. **Number Guessing Game** - guess a randomly generated number with higher/lower hints and attempt tracking.
2. **Word Guessing Game** - reveal a hidden word by guessing letters one at a time.
3. **Hangman** - classic word-guessing game with a limited number of incorrect attempts.
4. **21 Number Game** - turn-based number game where the player and computer race toward 21.
5. **Rock Paper Scissors** - play against a computer opponent using the classic three-choice rules.
6. **Compare Two PDFs** - compare two PDF files using file size and SHA-256 hashes.
7. **Emoji to Text** - convert supported emoji characters into readable Unicode names.
8. **Voice Recorder** - record microphone audio and save it as a WAV file.
9. **Screen Recorder** - capture screen frames over a selected duration.
10. **Mastermind** - guess a hidden numeric code using exact and misplaced-position feedback.
11. **2048 Logic** - practice the row-compression and tile-merging logic used in 2048.
12. **FLAMES** - calculate a FLAMES relationship result from two names.
13. **Creature Training Game** - train a simple game character using levels and experience points.
14. **Screenshot Tool** - capture and save a screenshot with a timestamped filename.
15. **Desktop Notifier** - display a desktop notification from Python.
16. **Live Weather Notifications** - retrieve current weather data and format it for notifications.
17. **Keyboard Event Monitor** - collect text entered directly into the running terminal session.
18. **Cows and Bulls** - numeric guessing game with exact-position and misplaced-digit feedback.
19. **Attendance Tracker** - store attendance records in a CSV file.
20. **Higher-Lower Game** - predict whether the next random number will be higher or lower.
21. **Fun Fact Generator** - display a random fact from a built-in collection.
22. **Payment Receipt Generator** - calculate totals and create a simple text receipt.
23. **Countdown Timer** - run a terminal countdown in minutes and seconds.
24. **Expense Tracker** - store expenses, categories, and totals using JSON.
25. **To-Do CLI** - create and save command-line tasks with completion status.
26. **Contact Book** - store and retrieve simple contact information.

## Run a Project

Most projects can be run directly:

```bash
python 10-mini-projects/01-number-guessing/main.py
```

The original standalone projects can be run with:

```bash
python 10-mini-projects/expense_tracker.py
python 10-mini-projects/todo_cli.py
python 10-mini-projects/contact_book.py
```

## Optional Dependencies

A few desktop, audio, screenshot, recording, and weather projects use third-party packages:

```bash
pip install -r 10-mini-projects/requirements.txt
```
