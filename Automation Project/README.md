# Automation Projects

Ten original Python automation projects inspired by the project ideas listed in the GeeksforGeeks Python project collection. The implementations in this repository were written independently and are intentionally structured for learning, readability, safety, and reuse.

## Projects

1. **Instagram Messages** - prepare and optionally send a direct message through Meta's supported messaging API.
2. **Birthday Post on Facebook** - generate birthday text and optionally publish it to a Facebook Page you manage.
3. **Birthday Mail** - send scheduled-style birthday greetings through SMTP.
4. **Software Testing** - discover and run Python unit tests automatically and summarize results.
5. **Google Search** - automate one or multiple browser searches from Python.
6. **LinkedIn Connections** - prepare a connection-review queue and open profiles for manual confirmation.
7. **Bulk Posting on Facebook** - publish content to multiple Facebook Pages you manage, with dry-run and rate limiting.
8. **Automated Email Messages** - send personalized email messages from a CSV contact list.
9. **Automate Backup** - create timestamped ZIP backups with SHA-256 verification.
10. **Hotword Detection** - detect configured hotwords from text streams, with an optional microphone adapter.

## Safety by Default

Social and messaging projects use **dry-run or manual-confirmation behavior by default**. Real sending requires explicit configuration and credentials. Keep automation limited to your own accounts, Pages, contacts, and authorized workflows.

## Optional Dependencies

Some projects use optional third-party packages:

```bash
pip install -r "Automation Project/requirements.txt"
```
